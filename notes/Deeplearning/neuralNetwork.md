The Big Picture (One Paragraph)
A neural network is just a mathematical function that transforms inputs into outputs through multiple layers of simple calculations.

You already know one: Linear Regression is a neural network with:

1 input layer

1 output layer

No hidden layers

No activation function

Everything else is just adding more layers and non-linearities.

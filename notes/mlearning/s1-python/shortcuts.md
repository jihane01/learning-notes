Essential Cell Shortcuts (Command Mode)
How to enter Command Mode: Press Esc (cell border turns blue)

Action	Shortcut
Create new cell below	B
Create new cell above	A
Delete current cell	DD (press D twice) 
Run current cell	Ctrl + Enter
Run cell and move to next	Shift + Enter
Run cell and insert below	Alt + Enter
Change to Markdown cell	M
Change to Code cell	Y 
Move cell up/down	Alt + ↑ or Alt + ↓ 
Copy cell	Ctrl + C
Cut cell	Ctrl + X
Paste cell	Ctrl + V
Undo cell operation	Z
